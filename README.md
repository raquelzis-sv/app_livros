# sobre o projeto
Feito para a aula de Programação para dispositivos móveis I, o projeto faz parte do tema "Organizador de livros, séries ou filmes", em que o usuário pode cadastrar livros, e a medida em que lê pode fazendo a marcação de lido ou também pela avaliação (gostar ou não gostar), a partir disso, ele poderá ver esses livros filtrados em telas diferentes, de acordo com a sua marcação.
